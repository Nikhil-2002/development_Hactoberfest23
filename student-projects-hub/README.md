# Student Projects Hub

A simple web app that:

- Lists student projects from various contributors
- Shows project name, description, tech stack, GitHub link, and contributor name
- Allows users to add their projects through a form (update constant or modify for backend)
- Has a clean, modern, responsive UI
- Two theme modes - dark and light


## Steps to add project

- Fork the repo
- Add your project to projects array in script.js
- Submit a Pull Request
- Get merged & listed on the site 🎉
